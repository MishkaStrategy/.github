# MishkaStrategy AI Skill Routing

**Policy version:** 2.0  
**Updated:** 2026-08-21  
**Scope:** ChatGPT, Codex, and compatible AI agents working on `MishkaStrategy` repositories

## Purpose

This file is optional reference guidance for choosing Skills or Plugins.

Use any available Skill, Plugin, tool, or normal workflow that is useful for the user's request and compatible with higher-priority platform and repository rules.

There is no organization-wide requirement for routing cadence, discovery cadence, Skill count, tool count, reload frequency, execution surface, workflow length, or response duration.

No organization-wide rule in this file requires or forbids switching chats, continuing a chat, selecting a particular model, using a particular reasoning level, limiting context, limiting tool calls, or minimizing the number of workflows used.

Repository-specific requirements and mandatory prerequisites of a Skill or Plugin still apply when that Skill or Plugin is actually used.
