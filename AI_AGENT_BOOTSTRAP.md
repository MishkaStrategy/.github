# MishkaStrategy AI Agent Bootstrap

**Policy version:** 3.0  
**Updated:** 2026-08-21

## Purpose

`MishkaStrategy/.github` is the canonical location for organization-wide AI policy.

## Bootstrap

For non-trivial work involving a MishkaStrategy repository:

- read the current `main` version of `MishkaStrategy/.github/AI_AGENT_POLICY.md`;
- read and follow the target repository's own applicable instructions;
- use GitHub as the repository source of truth unless the repository defines another canonical source.

`AI_SKILL_ROUTING.md` is reference guidance only and may be used when useful.

This bootstrap defines no session-duration, reasoning, model, context, tool-count, PR-count, milestone, handoff, rotation, or pacing rules.

Do not copy the full organization policy into project repositories; keep project-specific rules in the project that owns them.
